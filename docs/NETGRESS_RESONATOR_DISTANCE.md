# Расстояние от портала до каждого резонатора

Изменение Intel API 1.3.0, 29 октября 2026. Основной адрес: `https://api.netgress.ru`.

## Запрос

```http
GET /v1/intel/portals/{id}
Authorization: Bearer <intel_token>
```

Нового маршрута нет: расширен существующий ответ карточки портала. В каждом занятом слоте `resonators` добавлено поле `distance_m`.

## Пример одного занятого слота

```json
{"slot":0,"level":8,"current_xm":3000,"max_xm":6000,"owner":"ExampleAgent","distance_m":25.0}
```

`distance_m` — число, метры, от центра **этого портала** до сохранённой сервером позиции **этого резонатора**. Рассчитывается серверной географической функцией по координатам, не по экранным пикселям. Это не расстояние до игрока, не длина маршрута и не расстояние до соседнего резонатора. На API число дополнительно не округляется; для подписи UI можно округлить самостоятельно. Совпадающие позиции дают 0. Координаты самого резонатора этим полем не публикуются.

## Остальные поля и пустые слоты

- `resonators` по-прежнему содержит ровно восемь элементов. Пустой/уничтоженный слот — `null`, не объект с нулевой дистанцией.
- `slot` — номер слота 0–7, от севера по часовой стрелке.
- `owner` в занятом слоте — владелец **резонатора**, а верхнеуровневый `owner` — владелец/захвативший портал. Владельцы могут различаться; ники не подменяются друг другом. Эти поля уже существовали.
- `current_xm` и `max_xm` уже выдаются для каждого занятого слота.

## Совместимость и доступ

JSON-схема карточки остаётся `schema: 1`, изменение добавляет поле. Старые поля и порядок слотов сохранены. В кратком массиве `/v1/intel/map` нет резонаторов; для расстояний запрашивайте карточку по ID.

Авторизация, лимит 120 запросов/минуту на пользователя, CORS, ETag/304 и gzip остаются прежними. Для браузерной карты разрешены `https://pr0head.github.io` и `https://pr0head.gitverse.site`, а также два Intel-домена. При обновлении карточки заменяйте данные слотов актуальным ответом; на 304 используйте ранее сохранённый ответ той же карточки и сессии.

Полный контракт: [NETGRESS_MAP_API.md](NETGRESS_MAP_API.md). Машинная схема: [netgress-map-api.openapi.json](netgress-map-api.openapi.json).
