# Netgress API 1.4.0 — счёт и рейтинги ячеек

Базовый адрес — `https://api.netgress.ru`. Требуется `Authorization: Bearer <Intel-токен>`.

## Запрос

`GET /v1/intel/territorial-rating?kind=fields|links&territory=<территория>&cells=1`

`kind=fields` возвращает рейтинг по активным MU, `kind=links` — по активным линкам. `territory` принимает `world` (по умолчанию), код региона, код малой ячейки или канонический S2-токен уровня 4/6. Код ячейки можно передавать в любом регистре.

```text
/v1/intel/territorial-rating?kind=fields&territory=world
/v1/intel/territorial-rating?kind=fields&territory=NR02-CHARLIE&cells=1
/v1/intel/territorial-rating?kind=fields&territory=NR02-CHARLIE-08
/v1/intel/territorial-rating?kind=links&territory=NR02-CHARLIE-08
```

`cells=1` допускается для региона. Ответ включает баланс MU всех 16 дочерних ячеек. Топы дочерних ячеек загружаются отдельными запросами по мере открытия. Мировой баланс с метаданными расчёта остаётся доступен через `GET /v1/intel/score`, а прежний постраничный мировой рейтинг — через `GET /v1/intel/rating`.

## Ответ

`balance` и каждый элемент `cells` имеют `territory` (S2-токен либо `world`), `name` (код ячейки или «Мир»), `blue_mu` и `green_mu`. Баланс всегда измеряется в MU, включая запрос `kind=links`.

`top` содержит до десяти агентов. `self` содержит место авторизованного агента. Поля строки — `user_id`, `nickname`, `faction`, `value` и `rank`. У агента без вклада `self.value=0`, `self.rank=null`. При равных значениях порядок определяется UUID.

`as_of` — время чтения согласованного снимка. `status` относится к выбранному рейтингу, `mu_status` — к балансу MU. Значения — `ready`, `partial`, `unavailable`. При `partial` фоновые расчёты ещё догоняют изменения. При `unavailable` баланс MU отсутствует как рассчитанная величина, нулевые значения нельзя считать подтверждённым счётом.

Активные MU распределяются между ячейками серверным расчётом, уже используемым игрой. Линк учитывается в территории исходного портала. Числа — целые 64-битные значения.

Ответ имеет `Cache-Control: private, no-store`. Ошибки: 400 для неверного вида рейтинга, территории или запроса дочерних ячеек, 401 для недействительного токена, 403 при непринятых условиях, 404 при выключенном территориальном рейтинге, 429 при превышении лимита, 503 при временной недоступности.
