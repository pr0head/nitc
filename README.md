# NITC

**Современная интел-карта для игры Netgress.** Отдельный веб-клиент на базе
официального read-only [Map API](docs/NETGRESS_MAP_API.md): порталы, направленные
линки, поля, карточки порталов и журнал действий COMM — на полноценной карте со
слоями, фильтрами и переработанным UI/UX.

Это самостоятельная карта с собственным движком и интерфейсом. Мы переосмысливаем
подход к взаимодействию с картой, опираясь на многолетний опыт сообщества с
интел-картами (в духе IITC), но с нуля и в современном дизайне.

> Карта работает **только на чтение**. Никаких игровых действий она не выполняет:
> не перемещает игрока, не ставит резонаторы и моды, не создаёт линки и не атакует.
> Вход — под собственным аккаунтом Netgress; данные между игроками не передаются.

## Возможности

- **Карта.** Порталы, направленные линки и поля поверх подложек Yandex, Yandex
  гибрид, Google, Google гибрид, 2ГИС, OSM. Фильтры: диапазон уровней порталов
  (нейтральные — уровень 0) и таблица RES / ENL, где порталы, линки, поля и
  агенты включаются по фракциям отдельно. На отдалении, где сервер не отдаёт порталы, видны порталы с линками
  и полями (по их вершинам), клик открывает карточку. Строка статуса показывает,
  что реально загружено: порог длины линков, обрезанные ответы. Автообновление раз
  в 30 с, на скрытой вкладке — пауза. Карта помнит позицию и настройки.
- **Профиль и счёт.** Ник, фракция и уровень в плашке; мировой счёт MU фракций
  сверху по центру; по клику — окно с точными MU и долями,
  временем и статусом снимка, числом полей мира, и мировой рейтинг агентов
  (вкладки «Линки» и «Поля», как в игре) со своим местом.
- **Карточка агента.** Клик по нику (в карточке портала, в COMM, в плашке):
  уровень и AP, что агент держит сейчас, медали по ступеням (картинки
  классических медалей Ingress), статистика.
- **Трекер агентов.** Где агенты были за последние 3 часа — по событиям COMM,
  без лишних запросов: пин в последней точке (бледнеет со временем), с зума 14 —
  ник над ним, пунктирный след по прежним местам. По клику — все места агента со
  временем и действием; наведение на строку показывает точку на карте. «Показать
  на карте» в карточке агента центрирует карту и выделяет его след.
- **Подсветка.** Дуги на порталах (свободные слоты, слабые порталы, избранное),
  уровень текстом; у полей — площадь и MU.
- **Карточка портала.** Миниатюра фото (по нажатию — во весь экран), владелец,
  AP за снос, входящие/исходящие линки и поля, защита (щиты + линки), дальность
  линка по данным сервера, хаки с кулдауном. Моды с характеристиками по редкости,
  «роза» резонаторов по сторонам света с энергией портала в центре; у резонатора —
  здоровье и расстояние от портала, при наведении — линия до него на карте. На
  карте — радиус действия и радиус линка. История портала по журналу COMM (по нажатию): кто,
  когда и что делал с порталом. Ссылка на портал (`#p=…`) открывает его карточку;
  «маршрут» строит путь до портала в Яндекс Картах от вашего местоположения
  (недалеко — пешком, иначе на машине). Ссылка на точку (`#ll=широта,долгота[&z=зум]`)
  центрирует карту и отмечает точку прицелом; без `z` зум остаётся прежним.
- **COMM.** Лента событий видимой области: захваты, линки, поля и MU. Фильтры по
  типу и фракции, подгрузка старых и опрос новых событий. При наведении событие
  подсвечивается на карте, клик по порталу переводит к нему.
- **Избранное с группами.** Портал может состоять в нескольких группах (гардины,
  домашки, цели операции…); группы назначаются из карточки портала (▾ у
  звёздочки). Подсветка «Избранное» показывает порталы только тех групп, у
  которых включён «глаз»; поиск по названию; группу можно передать другому
  игроку через экспорт/импорт JSON. Импортируются и закладки порталов из IITC
  (папки → группы).
- **Ключи и инвентарь.** Свои ключи в карточке портала (свободные и в капсулах),
  подсветка «есть ключ» / число ключей; окно инвентаря с предметами по
  уровням и списком ключей.
- **Рисование и планы.** Линии и треугольники, клонирование, правка вершин,
  привязка к порталам. Именованные планы; экспорт копирует план на экране в
  формате IITC DrawTools, импорт добавляет присланный план отдельным новым планом —
  удобно делиться с другими игроками и между устройствами.
- **Моё местоположение.** Заметный янтарный маркер с пульсацией и стрелкой
  направления (по компасу или по ходу движения), радиус действия 40 м и бледный
  круг точности GPS. Кнопка «где я» центрирует карту и включает слежение — карта
  едет за вами, пока её не сдвинуть рукой. Карта открывается на последней
  просмотренной позиции; при первом входе — на местоположении.
- **Интерфейс** для десктопа и тач-устройств.

## Телефон

- **Android-приложение** — APK в [релизах](https://github.com/pr0head/nitc/releases)
  или по кнопке «Скачать приложение» на сайте: лёгкая оболочка, которая открывает
  опубликованную карту, поэтому обновления карты приходят без переустановки. Само
  выбирает зеркало (в российских сетях — GitVerse) и переключается, если карта
  не загрузилась.
- **Без установки APK** — открыть карту в браузере и выбрать «Добавить на
  главный экран»: карта откроется как отдельное приложение.

## Разработка

Стек: Vite + vanilla JS, движок карты — Leaflet.

```bash
npm install
npm run dev      # http://localhost:5173 (HMR)
npm run build    # статика в dist/
npm run preview  # проверка сборки
```

Локальная разработка работает: дев-сервер проксирует запросы к API
на своей стороне, обходя CORS-ограничение Netgress (localhost в списке
разрешённых нет). Публичная сборка ходит в API напрямую со своего разрешённого
origin `https://pr0head.github.io` — см. [docs/architecture.md](docs/architecture.md),
раздел «CORS и как его обходим».

Android-оболочка — в `android/` (см. [docs/architecture.md](docs/architecture.md),
раздел «Android-приложение»).

Инструкции для AI-агентов и участников — в [AGENTS.md](AGENTS.md) / [CLAUDE.md](CLAUDE.md).
