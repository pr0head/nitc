# NITC

**Современная интел-карта для игры Netgress.** Отдельный веб-клиент на базе
официального read-only [Map API](docs/NETGRESS_MAP_API.md): порталы, направленные
линки, поля, карточки порталов и журнал действий COMM — на полноценной карте со
слоями, фильтрами и переработанным UI/UX.

Это самостоятельная карта с собственным движком и интерфейсом. Мы переосмысливаем
подход к взаимодействию с картой, опираясь на многолетний опыт сообщества с
интел-картами (в духе IITC), но с нуля и в современном дизайне.

> Карта работает **только на чтение**. Никаких игровых действий она не выполняет:
> не перемещает игрока, не ставит резонаторы и моды, не создаёт линки и не атакует.
> Вход — под собственным аккаунтом Netgress; данные между игроками не передаются.

## Возможности (план)

- Порталы, линки и поля на карте со слоями и фильтрами (уровень, фракция, типы объектов).
- Карточка портала: резонаторы, моды и их характеристики, энергия, фото.
- Журнал COMM: захваты, линки, поля и MU в видимой области.
- Инструменты планирования: рисование линий/полей, импорт-экспорт схем.
- Современный отзывчивый интерфейс (десктоп + тач).

## Разработка

Стек: Vite + vanilla JS, движок карты — Leaflet.

```bash
npm install
npm run dev      # http://localhost:5173 (HMR)
npm run build    # статика в dist/
npm run preview  # проверка сборки
```

Локальная разработка работает: дев-сервер проксирует запросы к API
server-side, обходя CORS-ограничение Netgress. Для публичной сборки нужен
разрешённый origin — см. [docs/architecture.md](docs/architecture.md), раздел
«CORS и как его обходим».

Инструкции для AI-агентов и участников — в [AGENTS.md](AGENTS.md) / [CLAUDE.md](CLAUDE.md).
