# Medal pictures

The SVG files in this folder are the classic (pre-Prime) Ingress medals from the
**Vector Badges Set** by DabelCODY, published in
[cr0ybot/ingress-logos](https://github.com/cr0ybot/ingress-logos) (`badges/`).

(CC BY-NC-SA 3.0). These modified files are distributed under the same licence.

Changes made to the original work:
- the CorelDRAW export is reduced to plain shapes (styles, ids and metadata
  removed);
- the background, frame and symbol metal are marked with the classes `m-bg`,
  `m-fr` and `m-mt`, and the client recolours them for the medal tier at
  runtime (`../medal-art.js`); the bronze originals are not shipped as is;
- `mind_control.svg` is renamed to `mind_controller.svg`.
